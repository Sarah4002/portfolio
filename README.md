# Sara Belmahi — Portfolio

React + Vite. Blue/green theme, typing animations, interactive terminal.

    npm install
    npm run dev      # development
    npm run build    # production build in dist/

## Where to edit
- `src/data/projects.js` — projects (image, description, stack, type web/mobile/desktop)
- `src/data/tech.js` — skills and levels (Frontend / Backend / Database)
- `src/Components/Terminal/commands.jsx` — terminal commands, email/GitHub/LinkedIn
- `src/index.css` — colors (`--blue`, `--green`, `--grad`)
